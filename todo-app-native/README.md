# 待办事项 —— 原生 App 打包项目（HBuilderX 5+App）

这个目录是给 **HBuilderX** 用的打包工程。用 HBuilderX 打开它，就能把待办网站打包成
安卓 APK / iOS 安装包。

---

## 一、打开项目

1. 启动 **HBuilderX**
2. 左上角 **文件 → 打开目录**，选择本文件夹：
   ```
   todo-app-native
   ```
3. 打开后左侧项目管理器会出现「待办事项」项目，图标是 `5+App` 类型

> 如果 HBuilderX 提示项目类型不对，也可以：**文件 → 新建 → 项目 → 5+App**，
> 然后把本目录下的 `manifest.json`、`index.html`、`unpackage` 三个东西拷进新项目。

---

## 二、登录 DCloud 账号（云打包必需）

右上角头像 → **登录**。没有账号就点注册（免费，用邮箱或手机号）。
**云打包必须登录**，这一步无法跳过。

---

## 三、配置 manifest（只需点几下）

双击项目里的 `manifest.json`，会打开可视化配置界面：

| 标签页 | 要做什么 |
|---|---|
| **基础配置** | 点 AppID 右侧的 **「重新获取」**，让 DCloud 给你分配一个正式 AppID（**必须做**，否则打包会失败） |
| **App图标配置** | 已预置好全套图标。可选：选 `icon-source-1024.png` 后点「自动生成所有图标并替换」 |
| **App启动界面配置** | 已预置好启动图，可不改 |
| **App模块配置** | 保持默认即可 |
| **App权限配置** | 已配好网络权限，保持默认 |

---

## 四、打包（发行）

菜单栏 **发行 → 原生App-云打包**：

**打安卓 APK：**
- 勾选 **Android(apk包)**
- 安卓包名保持 `com.yuwann.todo`
- 证书：选 **「使用DCloud老版证书」**（测试用，免费、最省事）
  - 若要长期使用或上架，选「使用自有证书」，用 HBuilderX 自带的
    **运行 → 手机运行 → 证书管理** 生成一个
- 打包类型：**正式版**
- 点右下角 **打包**

**打 iOS 安装包：**
- 需要苹果开发者账号（$99/年）并提供证书与描述文件
- 没有的话可以先只打安卓包

打包是**云端进行**的，通常几分钟完成。完成后 HBuilderX 会给出下载链接，
APK 会下载到项目的 `unpackage/release/apk/` 目录下。

---

## 五、安装到手机

把生成的 APK 传到手机（微信文件传输助手、数据线、网盘都行），
在手机上点开安装即可。首次安装需要在系统里允许「安装未知来源应用」。

装好后桌面会出现「待办」图标，点开就是全屏应用。

---

## 六、以后如何更新 App 内容

App 内的页面是从网页版自动生成的。改了网页版之后：

```bash
cd todo-netlify
python3 build-native-html.py        # 重新生成 todo-app-native/index.html
```

然后在 HBuilderX 里重新打包一次即可。

> 注意：App 内的界面是**打包时固化**的，不会自动更新；
> 但**账号、待办数据、邮件提醒**都是实时连服务器的，这部分始终是最新的。

## 八、常见问题

**打包时提示 AppID 无效 / 未注册**
→ 回到 `manifest.json` 的「基础配置」，点 AppID 右侧「重新获取」。

**打包提示「未登录」**
→ 右上角登录 DCloud 账号。

**打包次数受限**
→ 免费账号每天云打包次数有限，用完可等第二天。

**App 打开后白屏**
→ 检查手机网络。App 的后端地址是 `https://yuwann-todo.netlify.app`，
如果该域名在当前网络下不可达（详见下方说明），请换网络或使用支持 IPv6 的网络。

**安卓可用但 iOS 不行**
→ iOS 打包必须要有苹果开发者账号和证书，这是苹果的规定。
没有的话，iPhone 用户直接用 Safari 把网页版「添加到主屏幕」，
效果和 App 几乎一样（全屏、独立图标、离线可用）。

---

## 附：后端地址说明

App 的后端固定指向：

```
https://yuwann-todo.netlify.app
```

该域名的 **IPv4 在国内已被阻断**，只有 IPv6 可达。
大部分手机在 Wi-Fi 下都能走 IPv6，因此通常可用；
若遇到打不开，换一个网络环境试试。

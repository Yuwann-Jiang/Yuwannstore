# Yuwannstore

这是我的个人小仓库。目前包含一个纯前端的 **待办事项（To-do List）** 小工具，可以记录任务及截止时间，并根据剩余时间自动标记紧急程度。

## 功能介绍

- **添加任务**：输入待办事项和截止日期、时间。
- **紧急程度提示**：按距离截止时间的长短显示不同颜色。
- **任务排序**：支持按剩余时间升序、降序或添加顺序查看。
- **剩余时间显示**：展示距截止时间还有多久；超时任务会标记“已超时”。
- **完成任务**：点击“已完成”即可从列表移除。
- **本地保存**：使用浏览器 `localStorage` 保存任务，刷新页面后仍会保留。

### 颜色规则

| 颜色 | 剩余时间 |
| --- | --- |
| 🔴 红色 | 24 小时以内（包括已超时） |
| 🟡 黄色 | 超过 24 小时、最多 4 天 |
| 🟢 绿色 | 超过 4 天 |

## 如何使用

1. 下载或克隆本仓库：

   ```bash
   git clone https://github.com/Yuwann-Jiang/Yuwannstore.git
   ```

2. 直接用浏览器打开项目根目录的 `index.html`。
3. 输入任务名称、选择截止时间，再点击“＋ 添加待办”。

**无需安装依赖，也无需运行后端服务。**

## 技术说明

- 使用原生 **HTML / CSS / JavaScript** 实现。
- 任务数据保存在当前浏览器的 `localStorage` 中（键名：`todo_items_v1`）。
- 页面每分钟更新一次剩余时间显示。
- **注意**：数据没有上传到服务器，也不会自动在不同浏览器或设备之间同步；清除浏览器站点数据可能导致任务丢失。

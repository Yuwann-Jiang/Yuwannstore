# 待办事项网站（带账号与跨设备同步）

自建的 Node 后端 + 前端，零外部依赖（只用 Node 内置模块），不需要安装任何 npm 包。

## 功能

- 用户名 + 密码注册 / 登录（密码用 scrypt 加盐哈希存储，不存明文）
- 登录同一账号，在不同设备上看到**同步的待办事项**
- 添加待办（含截止时间）、点击「已完成」删除该条
- 按剩余时间自动着色：红 ≤24 小时，黄 >24 小时且 ≤4 天，绿 >4 天
- 多用户数据互相隔离，各自只能看到自己的待办

## 启动

```bash
cd todo-server
node server.js
```

启动后：

- 本机访问：http://127.0.0.1:8123/
- 同一 Wi-Fi 下的手机 / 其他电脑：http://10.7.28.99:8123/
  （若本机 IP 变了，用 `ipconfig getifaddr en0` 重新查询）

换端口：`PORT=9000 node server.js`

## 数据存放

所有用户与待办数据都在 `data.json`（本目录下），首次注册时自动生成。
备份就是复制这个文件；删除它即可清空所有账号与待办。

## 目录结构

```
todo-server/
├── server.js           后端：鉴权 + 待办 API + 托管前端
├── public/index.html    前端页面（登录界面 + 待办列表）
└── data.json           数据文件（自动生成）
```

## 部署到公网（可选，尚未做）

目前后端只在你电脑上运行，所以只有**同一局域网**的设备能同步。
若要让 GitHub Pages 上的公开网址也支持账号登录，需要把这个后端部署到一台有公网地址的服务器
（如 Render / Railway / 飞书云主机等），然后把 `public/index.html` 顶部的

```js
const API_BASE = "";
```

改成后端公网地址，例如 `const API_BASE = "https://your-backend.onrender.com";` 再重新推送即可。
